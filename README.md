# Минус 30 кг — Android-проект

Нативное приложение для Android на Kotlin + Jetpack Compose. Начальные данные настроены под пользователя: мужчина, 33 года, рост 180 см, начальный вес 123 кг, цель 93 кг.

## Функции
- экран текущего веса и прогресса к цели;
- изменение и локальное сохранение веса;
- добавление калорий вручную;
- учёт стаканов воды;
- поле окружности талии;
- пример дневного меню и напоминания о безопасной активности.

Данные сохраняются локально на устройстве через SharedPreferences. Интернет и регистрация не нужны.

## Как собрать APK
1. Установите Android Studio на компьютер и Android SDK (API 35).
2. Откройте папку `minus30kg` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Передайте APK на Samsung, разрешите установку из выбранного источника и установите.

В этой среде Android SDK и Gradle не установлены, поэтому готовый APK здесь не собран; архив содержит исходный Android Studio проект.

## Медицинское примечание
Приложение не заменяет врача. План питания — общий пример, а не диагноз или индивидуальное медицинское назначение. При ИМТ около 38 полезно проверить давление, глюкозу/HbA1c и обсудить лечение ожирения с врачом. Не стремитесь к резкому снижению веса.
