# Как получить APK прямо с телефона Samsung (без компьютера)

Готовый APK в архиве пока отсутствует: его нужно собрать в облаке. Для этого нужен аккаунт GitHub и интернет. GitHub — сторонний сервис; если не хотите создавать аккаунт, попросите человека с компьютером собрать проект.

## Шаги
1. Откройте в браузере телефона https://github.com и войдите или создайте аккаунт.
2. Нажмите **+ → New repository**. Назовите репозиторий `minus-30-kg`, выберите **Private**, затем **Create repository**.
3. В новом репозитории нажмите **Add file → Upload files**.
4. Распакуйте архив `Minus_30_kg_Android_project.zip` на телефоне (например, приложением «Мои файлы»). Загрузите ВСЕ файлы и папки из внутренней папки `minus30kg` в корень репозитория. Включая папку `.github` (если она не видна в распаковщике, включите показ скрытых файлов или загрузите проект через GitHub web editor).
5. Нажмите **Commit changes**. Подождите, пока workflow завершится.
6. Откройте вкладку **Actions** → **Build Minus 30 kg APK** → последний запуск. Внизу страницы в разделе **Artifacts** нажмите `Minus-30-kg-APK`, чтобы скачать ZIP с APK.
7. Откройте скачанный ZIP в «Мои файлы» и извлеките `app-debug.apk`.
8. Нажмите APK. Если Samsung попросит разрешение, разрешите установку неизвестных приложений именно для браузера или «Мои файлы», из которого открываете файл. Устанавливайте APK только из своего репозитория.

## Если сборка не запустилась
В репозитории откройте **Actions**, выберите неудачный запуск и посмотрите красный шаг. Не публикуйте токены, пароли или личные данные. Пришлите скриншот ошибки — помогу разобраться.

## О приложении
Приложение сохраняет записи локально на устройстве. Это не медицинское устройство и не заменяет врача. Цель 93 кг — долгосрочная цель; безопасный темп часто около 0,5–1 кг в неделю. Перед интенсивными тренировками проверьте давление и обсудите здоровье с врачом.
